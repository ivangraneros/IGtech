## 🛠️ Stack Tecnológico

Nuestros desarrollos se basan en un ecosistema tecnológico moderno que garantiza rendimiento, seguridad y mantenimiento a largo plazo:

* **Frontend:** React, Vite, Tailwind CSS, JavaScript (ES6+).
* **Backend & APIs:** Node.js, Express, Python (Django), Arquitecturas REST.
* **Bases de Datos & Cloud:** MongoDB, Firebase Firestore, Supabase (con políticas de seguridad RLS).
* **DevOps & Control de Versiones:** Docker, Git, GitHub, Vercel.
